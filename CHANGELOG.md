# Changelog

## 1.0.1

- Add a GitHub Actions release workflow with artifact attestations.
- Add issue templates for bug reports and feature requests.
- Refresh documentation after the plugin was listed in the Obsidian community directory.

## 1.0.0

- Initial public release.
- Sort root-level folders with a custom order.
- Reorder folders with drag and drop, position numbers, or Up/Down buttons.
- Add current root folders or add future folders by name.
- Mark missing folders and create them from settings.
- Optional handling for new, renamed, and deleted root folders.
- English and Chinese settings UI.
